========================
PROJECT GOAL
========================

Create an AI Image Editor that automatically separates an image into semantic layers.

Instead of Photoshop layers, every detected object becomes its own editable layer.

Example:

Input

Person standing near a red car with mountains and sky.

Automatically create

Layer 1
Person

Layer 2
Car

Layer 3
Road

Layer 4
Sky

Layer 5
Mountains

Layer 6
Trees

Layer 7
Background

Every layer should be editable independently.

Finally merge every edited layer into a single high-quality image.

No manual masking should be required.
